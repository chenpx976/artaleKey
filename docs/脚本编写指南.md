## 脚本格式

ArtaleKey 使用 YAML 格式定义自动化脚本。基本结构如下：

```yaml
name: "脚本名称"
description: "脚本描述"
version: "1.0"
author: "作者名"

execution:
  mode: "continuous"  # 执行模式
  duration: 60        # 持续时间（秒）- 仅 duration 模式需要
  iterations: 10      # 迭代次数 - 仅 iterations 模式需要

window:
  auto_activate: true              # 启动时自动激活游戏窗口
  pause_on_focus_loss: true        # 失去焦点时自动暂停
  target_window: "MapleStory Worlds"  # 目标窗口名称

operations:
  - type: "press"
    key: "a"
  # ... 更多操作
```

---

## 执行模式

### 1. continuous（连续模式）
无限循环执行，直到手动停止。

```yaml
execution:
  mode: "continuous"
```

### 2. duration（时长模式）
执行指定的时长（秒）后自动停止。

```yaml
execution:
  mode: "duration"
  duration: 300  # 执行 5 分钟
```

### 3. iterations（迭代模式）
执行指定的次数后自动停止。

```yaml
execution:
  mode: "iterations"
  iterations: 10  # 执行 10 次
```

## 操作类型

### 1. press - 单次按键
快速按下并释放一个键。

```yaml
- type: "press"
  key: "a"
```

### 2. long_press - 长按
按住键一段时间后释放。

```yaml
- type: "long_press"
  key: "s"
  duration: 500  # 按住 500 毫秒
```

### 3. hold - 按住不放
按下键并保持按住状态，直到遇到 release 操作。

```yaml
- type: "hold"
  key: "shift"
```

**重要**：使用 `hold` 后必须配合 `release` 来释放按键！

### 4. release - 释放按键
释放之前通过 `hold` 按住的键。

```yaml
- type: "release"
  key: "shift"
```

### 5. delay - 延迟等待
暂停执行指定的时间。

```yaml
- type: "delay"
  duration: 1000  # 等待 1000 毫秒（1 秒）
```

### 6. repeat - 重复操作
重复执行一组操作指定的次数。

```yaml
- type: "repeat"
  count: 3
  operations:
    - type: "press"
      key: "q"
    - type: "delay"
      duration: 200
```

### 7. combo - 组合键
同时按下多个键。

```yaml
- type: "combo"
  keys: ["shift", "q"]
  duration: 100  # 按住 100 毫秒
```

## 高级用法

### 1. 按住攻击键的同时移动

这是一个常见的游戏场景：按住攻击键，同时进行移动操作。

```yaml
name: "按住攻击并移动"
description: "按住 F 键攻击，同时左右移动"
version: "1.0"
author: "User"

execution:
  mode: "continuous"

window:
  auto_activate: true
  pause_on_focus_loss: true
  target_window: "MapleStory Worlds"

operations:
  # 按住攻击键 F
  - type: "hold"
    key: "f"

  # 等待 10-15 秒（这里用 12 秒作为中间值）
  - type: "delay"
    duration: 12000

  # 往左走两下
  - type: "press"
    key: "left"
  - type: "delay"
    duration: 100
  - type: "press"
    key: "left"
  - type: "delay"
    duration: 100

  # 往右走两下
  - type: "press"
    key: "right"
  - type: "delay"
    duration: 100
  - type: "press"
    key: "right"
  - type: "delay"
    duration: 100

  # 释放攻击键 F
  - type: "release"
    key: "f"

  # 短暂延迟后重复
  - type: "delay"
    duration: 500
```

**注意**：目前脚本不支持随机延迟，但你可以手动调整 `duration` 值来模拟不同的等待时间。

### 2. 复杂的技能循环

```yaml
name: "复杂技能循环"
description: "包含 buff、攻击、移动的完整循环"
version: "1.0"
author: "User"

execution:
  mode: "continuous"

window:
  auto_activate: true
  pause_on_focus_loss: true
  target_window: "MapleStory Worlds"

operations:
  # 开启 buff
  - type: "press"
    key: "f1"
  - type: "delay"
    duration: 500

  # 按住攻击键
  - type: "hold"
    key: "a"

  # 攻击 5 秒
  - type: "delay"
    duration: 5000

  # 释放攻击键
  - type: "release"
    key: "a"

  # 移动到新位置
  - type: "long_press"
    key: "left"
    duration: 1000

  # 继续攻击
  - type: "hold"
    key: "a"
  - type: "delay"
    duration: 5000
  - type: "release"
    key: "a"

  # 移动回来
  - type: "long_press"
    key: "right"
    duration: 1000

  # 等待技能冷却
  - type: "delay"
    duration: 2000
```

### 3. 嵌套重复

```yaml
name: "嵌套重复示例"
description: "在重复中嵌套另一个重复"
version: "1.0"
author: "User"

execution:
  mode: "iterations"
  iterations: 5

window:
  auto_activate: true
  pause_on_focus_loss: true
  target_window: "MapleStory Worlds"

operations:
  # 外层循环：重复 3 次
  - type: "repeat"
    count: 3
    operations:
      # 按 Q 键
      - type: "press"
        key: "q"
      - type: "delay"
        duration: 300

      # 内层循环：快速按 A 键 5 次
      - type: "repeat"
        count: 5
        operations:
          - type: "press"
            key: "a"
          - type: "delay"
            duration: 100

      # 等待
      - type: "delay"
        duration: 1000
```

## 注意事项

### 1. hold 和 release 必须配对
使用 `hold` 按住键后，**必须**使用 `release` 释放，否则键会一直保持按下状态！

❌ **错误示例**：
```yaml
- type: "hold"
  key: "shift"
# 忘记释放！
```

✅ **正确示例**：
```yaml
- type: "hold"
  key: "shift"
# ... 其他操作 ...
- type: "release"
  key: "shift"
```

### 2. 时间单位
- `duration` 字段的单位是**毫秒**（ms）
- 1 秒 = 1000 毫秒
- 例如：`duration: 5000` 表示 5 秒

### 3. 按键名称必须小写
所有按键名称必须使用小写字母。

❌ 错误：`key: "A"` 或 `key: "SHIFT"`
✅ 正确：`key: "a"` 或 `key: "shift"`

### 4. YAML 缩进
YAML 使用**2 个空格**进行缩进，不要使用 Tab。

### 5. 脚本验证
保存脚本前，点击"Validate"按钮验证格式是否正确。

### 6. 窗口焦点
- 启用 `pause_on_focus_loss` 后，切换到其他窗口时脚本会自动暂停
- 切回游戏窗口时会自动恢复执行
- 这可以防止在非游戏窗口中误操作

## 使用 AI 生成脚本

如果你不熟悉 YAML 语法，可以使用 **AI 生成**功能：

1. 点击 **"🤖 AI Generate"** 按钮
2. 用自然语言描述你的需求，例如：
   - "创建一个攻击脚本，按 A 键攻击，等待 800ms，按 S 键攻击，等待 800ms，循环执行"

4. 生成后可以在编辑器中查看和修改

## 常见问题

### Q: 如何实现随机延迟？
A: 目前脚本不支持随机数功能。你可以创建多个脚本，每个使用不同的延迟时间，然后手动切换使用。

### Q: 可以同时按住多个键吗？
A: 可以！使用多个 `hold` 操作，然后在需要时分别 `release`：

```yaml
- type: "hold"
  key: "shift"
- type: "hold"
  key: "a"
# ... 其他操作 ...
- type: "release"
  key: "a"
- type: "release"
  key: "shift"
```

### Q: 脚本执行时可以手动操作吗？
A: 可以，但不建议。脚本执行时会模拟键盘输入，可能会与你的手动操作冲突。建议使用"暂停"功能后再手动操作。

### Q: 如何停止正在执行的脚本？
A: 点击 **"⏹ Stop"** 按钮即可立即停止脚本执行，所有按住的键会自动释放。

### Q: 脚本可以嵌套多少层 repeat？
A: 最多支持 3 层嵌套。
