# OCR数据提取改进文档

## 改进概述

本次改进主要针对ArtaleKey的OCR数据提取功能，特别是对游戏中经验值、等级和金钱数据的识别准确性进行了优化。

## 主要问题

在之前的版本中，OCR系统存在以下问题：

1. **经验值识别失败**：无法正确识别"巨522892[4808%"这种格式的经验值文本
2. **百分比解析错误**：OCR可能将"48.08%"识别为"4808%"，导致数据验证失败
3. **置信度过滤过严**：一些重要的游戏数据因置信度较低被过滤掉

## 解决方案

### 1. 增强经验值正则表达式模式

添加了新的正则表达式模式来处理包含前缀字符的经验值格式：

```python
# 新增的模式
r'[^\d]*(\d+)\s*[\[\(](\d+(?:\.\d+)?)%',  # 巨522892[4808% (包含前缀字符)
r'(\d{4,})\s*[\[\(](\d+(?:\.\d+)?)%?',    # 522892[4808 (4位以上数字+百分比)
```

### 2. 百分比自动修正机制

实现了智能的百分比修正逻辑，处理OCR识别中的小数点丢失问题：

```python
# 百分比修正逻辑
if exp_percentage > 100:
    # 尝试将百分比除以100（如4808 -> 48.08）
    if exp_percentage <= 10000:
        exp_percentage = exp_percentage / 100
    else:
        # 百分比过大，可能是识别错误，跳过
        continue
```

### 3. 动态置信度阈值

根据文本的游戏相关性动态调整置信度要求：

```python
# 对游戏相关文本使用更低的置信度要求
is_relevant = self._is_game_relevant_text(text)
min_confidence = 0.1 if is_relevant else 0.5
```

### 4. 增强的数据验证

添加了更严格的数据合理性验证：

- 经验值必须大于0
- 百分比必须在0-100%范围内
- 等级必须在1-300范围内
