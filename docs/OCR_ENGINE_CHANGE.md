# OCR引擎变更说明

## 变更概述

将ArtaleKey应用程序的OCR引擎从PaddleOCR更改为EasyOCR，以简化依赖和提高兼容性。

## 变更详情

### 1. 依赖变更

**移除的依赖：**
- `paddlepaddle>=2.5.0`
- `paddleocr>=2.7.0`

**添加的依赖：**
- `easyocr>=1.7.0`

### 2. 代码变更

#### 2.1 OCR引擎初始化
- 将`_load_ocr_engine()`方法从PaddleOCR改为EasyOCR
- 支持英文和简体中文识别：`['en', 'ch_sim']`
- 禁用GPU以避免兼容性问题

#### 2.2 OCR识别方法
- `_perform_ocr()`方法更新为使用EasyOCR的`readtext()`方法
- 输入格式从BGR改为RGB（EasyOCR需要RGB格式）
- 结果格式调整为EasyOCR的输出格式

#### 2.3 可视化功能
- 将`_create_paddleocr_visualization()`改为`_create_easyocr_visualization()`
- 使用PIL的ImageDraw替代PaddleOCR的draw_ocr函数
- 支持多边形边框绘制和文本标注

### 3. 功能特性

#### 3.1 保持的功能
- 游戏数据提取（等级、经验、金钱）
- 文本相关性过滤
- 置信度阈值控制
- 可视化结果输出
- JSON结果保存

#### 3.2 改进的功能
- 更简单的依赖管理
- 更好的跨平台兼容性
- 减少内存占用
- 更快的启动时间

### 4. 配置变更

无需修改配置文件，所有现有配置保持兼容。

### 5. 输出文件变更

- 可视化文件名从`paddleocr_viz_*.png`改为`easyocr_viz_*.png`
- JSON结果中的`source`字段从`paddleocr`改为`easyocr`
- 其他输出格式保持不变

### 6. 性能对比

| 特性 | PaddleOCR | EasyOCR |
|------|-----------|---------|
| 依赖大小 | 较大 | 较小 |
| 启动时间 | 较慢 | 较快 |
| 内存占用 | 较高 | 较低 |
| 识别精度 | 高 | 高 |
| 多语言支持 | 丰富 | 良好 |

### 7. 使用说明

#### 7.1 安装依赖
```bash
pip install easyocr>=1.7.0
```

#### 7.2 首次运行
EasyOCR会自动下载必要的模型文件，首次运行可能需要较长时间。

#### 7.3 支持的语言
- 英文 (en)
- 简体中文 (ch_sim)

### 8. 故障排除

#### 8.1 常见问题
1. **模型下载失败**：检查网络连接，EasyOCR需要下载预训练模型
2. **内存不足**：EasyOCR对内存要求较低，但仍需要足够的RAM
3. **识别精度问题**：可以调整置信度阈值（默认0.5）

#### 8.2 日志信息
- 成功加载：`EasyOCR引擎加载成功`
- 识别完成：`EasyOCR识别完成，检测到 X 个文本区域`
- 可视化保存：`EasyOCR可视化已保存: path`

### 9. 向后兼容性

此变更保持了API的向后兼容性，现有的调用代码无需修改。
