# ArtaleKey UI 改进总结

## 改进目标

根据用户反馈，对ArtaleKey应用程序的用户界面进行了重大改进，主要目标包括：

1. **统一功能开关控制** - 解决快速向上功能有两个开关的问题
2. **合并可视化功能** - 将可视化功能集成到OCR标签页中
3. **优化窗口状态显示** - 将窗口状态信息移到状态栏，简化界面
4. **改进游戏数据展示** - 将最新游戏数据移到OCR标签页中统一展示

## 详细改进内容

### 1. 快速向上功能开关统一

#### 问题描述
- 原来的快速向上功能有两个开关：`HotkeyCard`内部一个，外层还有一个全局开关
- 用户困惑，不清楚应该使用哪个开关

#### 解决方案
- **修改 `HotkeyCard` 组件**：
  - 添加 `enable_internal_switch` 参数控制是否显示内部开关
  - 当 `enable_internal_switch=False` 时，隐藏内部的"启用此功能"复选框
- **重构 `QuickUpTab`**：
  - 将功能控制组移到顶部，热键配置组移到下面
  - 使用外层的"启用快速向上功能"作为唯一开关
  - 开关状态与热键配置同步，启用时显示触发键信息

#### 代码变更
```python
# artalekey/ui/components.py - HotkeyCard类
def __init__(self, hotkey_id: str, parent=None, enable_internal_switch: bool = True):
    # 控制是否显示内部开关

# artalekey/ui/tabs/quick_up_tab.py - QuickUpTab类
self._hotkey_card = HotkeyCard("default", enable_internal_switch=False)  # 禁用内部开关
```

### 2. 可视化功能合并到OCR标签页

#### 问题描述
- 可视化是OCR结果的展示，应该作为OCR功能的一部分
- 独立的可视化标签页显得冗余

#### 解决方案
- **删除独立的可视化标签页** (`visualization_tab.py`)
- **将可视化组件集成到OCR标签页**：
  - 在OCR配置下面添加"游戏数据可视化"组
  - 包含完整的QtVisualizationWidget功能
- **更新标签页管理器**：
  - 从 `TAB_CONFIGS` 中移除可视化标签页配置
  - 更新信号处理逻辑，将可视化刷新调用改为OCR标签页方法

#### 代码变更
```python
# artalekey/ui/tabs/ocr_tab.py
# 可视化组（合并到OCR标签页）
visualization_group = QGroupBox("游戏数据可视化")
self._visualization_widget = QtVisualizationWidget()

# artalekey/ui/tabs/__init__.py - 移除可视化标签页
TAB_CONFIGS = [
    {"name": "quick_up", "title": "快速向上", "class": QuickUpTab},
    {"name": "ocr", "title": "OCR识别", "class": OCRTab},
    {"name": "settings", "title": "设置", "class": SettingsTab},
]
```

### 3. 窗口状态移到状态栏

#### 问题描述
- 窗口状态组件占用了大量界面空间
- 用户认为应该放在应用最下面的状态栏中

#### 解决方案
- **移除 `WindowStatusWidget` 组件**：
  - 删除大的窗口状态显示组件
  - 不再在主界面中占用空间
- **在状态栏中集成窗口状态**：
  - 左侧显示窗口状态文本（已激活/未激活/未运行）
  - 右侧添加小巧的"激活窗口"按钮
  - 使用颜色标识状态（绿色=已激活，橙色=未激活，红色=未运行）

#### 代码变更
```python
# artalekey/ui/tabbed_main_window.py
def _init_status_bar(self):
    """初始化状态栏"""
    # 窗口状态标签
    self.window_status_label = QLabel("窗口状态: 检测中...")
    status_bar.addWidget(self.window_status_label)
    
    # 激活窗口按钮
    self.activate_button = QPushButton("激活窗口")
    status_bar.addPermanentWidget(self.activate_button)
```

### 4. 游戏数据展示重新组织

#### 问题描述
- 最新游戏数据原来在窗口状态组件中显示
- 与OCR功能相关的数据应该集中展示

#### 解决方案
- **在OCR标签页中添加游戏数据组**：
  - 在OCR状态和可视化之间插入"最新游戏数据"组
  - 显示等级、经验、金钱、更新时间等信息
  - 包含数据库统计信息
- **时间转换优化**：
  - 添加UTC到北京时间的转换功能
  - 统一时间显示格式

## 用户体验改进

### 1. 界面更加简洁
- 移除了占用大量空间的窗口状态组件
- 标签页内容更加丰富和集中

### 2. 功能逻辑更清晰
- 快速向上功能只有一个开关，避免用户困惑
- OCR相关的所有功能（配置、状态、数据展示、可视化）集中在一个标签页

### 3. 信息展示更合理
- 窗口状态在状态栏中简洁显示，不占用主要空间
- 游戏数据在OCR标签页中展示，与功能更相关

### 4. 操作更便利
- 激活窗口按钮在右下角，位置固定且容易访问
- 功能开关状态明确，操作逻辑简单

## 技术实现要点

### 1. 组件复用和扩展
- `HotkeyCard` 增加参数控制内部开关显示

### 2. 信号处理更新
