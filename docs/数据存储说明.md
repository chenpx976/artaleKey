# ArtaleKey 数据存储说明

## 数据存储位置

ArtaleKey 使用系统标准的用户数据目录来存储所有数据，确保数据的持久性和安全性。

### 各平台数据目录

- **macOS**: `~/Library/Application Support/ArtaleKey/`
- **Windows**: `%APPDATA%\ArtaleKey\`
- **Linux**: `~/.local/share/ArtaleKey/`

## 存储内容

数据目录包含以下内容：

1. **game_data.db** - SQLite数据库，存储所有OCR识别的游戏数据
2. **screenshots/** - 截图文件夹，保存OCR处理的原始截图
3. **annotated_images/** - 注释图像文件夹，保存带有OCR识别标注的图像
4. **ocr_results/** - OCR结果文件夹，保存详细的OCR识别结果
5. **export_*.json** - 导出的数据文件

## 数据持久性保证

### 重新安装不丢失数据

新版本的数据存储方案使用系统标准的用户数据目录，具有以下优势：

1. **跨安装持久性** - 即使应用程序重新安装到不同位置，数据仍然保留
2. **用户级隔离** - 每个用户的数据独立存储，不会相互影响
3. **系统兼容性** - 遵循各操作系统的标准数据存储规范
4. **备份友好** - 大多数系统备份方案会自动包含这些目录

### 旧版本数据迁移

如果你之前使用的是旧版本：

1. 旧版本数据可能存储在应用程序安装目录附近
2. 新版本会自动在标准目录创建新的数据存储
3. 如需迁移旧数据，可以手动复制 `game_data.db` 文件到新的数据目录

## 数据管理功能

在应用程序的"设置"标签页中，提供了以下数据管理功能：

### 打开数据目录
- 点击"打开数据目录"按钮，系统文件管理器会自动打开数据目录
- 方便用户查看、备份或管理数据文件

### 数据清理
- 点击"清理30天前数据"可以删除过期的历史数据
- 有助于控制数据库大小和提高性能

### 数据导出
- 点击"导出数据"可以将数据导出为JSON格式
- 导出文件自动保存到数据目录，文件名包含时间戳

## 数据安全建议

1. **定期备份** - 建议定期备份整个数据目录
2. **权限控制** - 数据目录默认只有当前用户可访问
3. **空间监控** - 长期使用后注意监控数据目录的磁盘空间使用

## 故障排除

如果遇到数据相关问题：

1. 检查数据目录是否存在和可访问
2. 确认应用程序有足够的文件系统权限
3. 查看应用程序日志中的数据库相关错误信息
4. 如有必要，可以删除数据目录让应用程序重新创建

## 开发者信息

数据存储实现位于 `artalekey/core/database.py` 文件中的 `_get_app_data_dir()` 函数。
