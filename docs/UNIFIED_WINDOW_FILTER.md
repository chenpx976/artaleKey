# 统一窗口过滤功能说明

## 改进概述

ArtaleKey 现在已经实现了统一的窗口过滤配置，所有需要窗口检测的功能都使用同一个配置，避免了多处设置的复杂性。

## 功能特性

### ✅ 统一配置管理
- **单一配置入口**: 所有窗口过滤功能统一在"设置"标签页中配置
- **默认启用**: 首次使用时自动启用窗口过滤，默认目标应用为"MapleStory Worlds"
- **自动同步**: 修改目标应用时，所有相关功能自动同步更新

### 🎯 涵盖的功能
以下功能现在都使用统一的窗口过滤配置：

1. **快速向上功能** - 只在目标窗口激活时响应 W+↑ 快捷键
2. **OCR识别功能** - 只在目标窗口激活时响应 C 键触发
3. **窗口状态监控** - 实时监控目标窗口的激活状态
4. **热键监听器** - 根据窗口状态启用/禁用快捷键

### 🔧 配置结构
```json
{
  "window_filter": {
    "enabled": true,                    // 默认启用
    "target_app": "MapleStory Worlds"   // 统一的目标应用
  }
}
```

## 使用方法

### 1. 基础设置（自动完成）
- 首次启动时，窗口过滤功能**自动启用**
- 默认目标应用已设置为"MapleStory Worlds"
- 无需手动配置即可直接使用

### 2. 自定义设置
如需更改目标应用：
1. 打开"设置"标签页
2. 在"目标应用设置"组中找到"窗口过滤"
3. 修改"目标应用"下拉框中的应用名称
4. 或点击"使用默认应用"/"设为当前应用"按钮

### 3. 功能状态
- ✅ **绿色状态**: 目标窗口已激活，快捷键功能可用
- ⏸️ **橙色状态**: 目标窗口未激活，快捷键已暂停
- ❌ **灰色状态**: 窗口过滤已禁用

## 技术实现

### 信号同步机制
```python
# 主窗口监听目标应用变更
self.target_selector.target_app_changed.connect(self.on_target_app_changed)

def on_target_app_changed(self, target_app):
    """目标应用变更时同步更新所有组件"""
    # 同步更新热键监听器
    self.hotkey_listener.set_target_window_name(target_app)
    # 保存配置
    self.save_config()
```

### 统一配置管理
- **配置键**: `window_filter`
- **默认值**: `{"enabled": true, "target_app": "MapleStory Worlds"}`
- **自动保存**: 任何配置变更都会立即保存到系统配置

### 组件协调
1. **SimpleTargetSelector**: 负责UI配置和用户交互
2. **ActiveWindowMonitor**: 负责实时窗口状态监控
3. **HotkeyListener**: 负责根据窗口状态启用/禁用快捷键
4. **EnhancedOCRManager**: 负责OCR功能的窗口检测

## 优势对比

### 改进前 ❌
- OCR功能有独立的目标窗口设置
- 热键管理器有自己的窗口检测逻辑
- 窗口过滤设置散落在多个地方
- 配置不一致可能导致功能异常

### 改进后 ✅
- 统一的窗口过滤配置入口
- 所有功能自动同步目标窗口设置
- 默认启用，开箱即用
- 配置一致性得到保证

- **智能检测**: 自动识别游戏窗口激活状态
- **无干扰**: 只在游戏窗口中响应快捷键

### 🔧 灵活扩展
- 支持任意应用程序

## 故障排除

### Q: 快捷键不响应？
A: 检查"设置"页面中的窗口过滤是否启用，目标应用是否正确

### Q: OCR功能无法触发？
A: 确保在目标窗口中按下C键，检查窗口过滤状态是否为绿色

### Q: 想要支持其他游戏？
A: 在目标应用下拉框中输入新的应用名称，或使用"设为当前应用"功能
