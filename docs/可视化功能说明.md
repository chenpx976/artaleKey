# ArtaleKey 可视化功能说明

## 概述

ArtaleKey 现在包含了强大的可视化功能，帮助玩家分析经验获取效率和游戏进度。

## 功能特性

### 1. 经验增长趋势图

- **折线图显示**: 实时显示经验值随时间的变化
- **等级过滤**: 可以按特定等级筛选数据
- **时间范围**: 支持1小时、6小时、12小时、24小时的数据展示
- **数据统计**: 显示经验增长、最低/最高经验值等统计信息

### 2. 时间段经验统计

- **时间间隔**: 支持3分钟、5分钟、10分钟的统计间隔
- **详细数据**: 显示每个时间段的：
  - 时间范围
  - 持续时间
  - 经验获取量
  - 平均等级
  - 记录数量

### 3. 自动刷新

- 每30秒自动刷新数据
- 手动刷新按钮
- 实时更新统计信息

## 使用方法

### 访问可视化页面

1. 启动 ArtaleKey 应用
2. 点击 "可视化" 标签页

### 控制面板操作

1. **等级过滤**: 选择特定等级或"全部等级"
2. **时间范围**: 选择要查看的时间范围
3. **统计间隔**: 设置时间段统计的间隔
4. **刷新数据**: 手动刷新当前数据

### 读取图表

- **X轴**: 时间
- **Y轴**: 经验值
- **蓝色折线**: 经验增长趋势
- **数据点**: 每次OCR识别的记录

### 解读统计表

- **时间段**: 统计的时间范围
- **经验获取**: 该时间段内的经验增长
- **平均等级**: 该时间段的平均等级
- **记录数**: 该时间段内的OCR记录数量

## 数据管理

### 删除历史数据功能修复

现在删除历史数据功能已经修复，可以正常删除指定天数前的旧数据：

1. 进入 "设置" 标签页
2. 点击 "清理30天前数据" 按钮
3. 系统会显示删除的记录数量

### 导出数据

支持将游戏数据导出为JSON格式：

1. 进入 "设置" 标签页  
2. 点击 "导出数据" 按钮
3. 数据将保存到 `ocr_data/export_YYYYMMDD_HHMMSS.json`

## 技术细节

- 使用 matplotlib 绘制图表
- 数据存储在 SQLite 数据库中
- 支持高分辨率显示
- 自动处理时区和时间格式

## 注意事项

1. 可视化功能需要有OCR识别的历史数据
2. 初次使用时可能没有足够数据显示趋势
3. 建议使用一段时间积累数据后再查看趋势分析
4. 删除数据操作不可恢复，请谨慎操作

## 故障排除

### 图表显示"暂无数据"

- 检查是否已开启OCR功能
- 确认是否有足够的历史数据
- 调整时间范围或等级过滤设置

### 统计表为空

- 确认选择的时间间隔内有足够的数据
- 检查OCR识别是否正常工作
- 尝试调整统计间隔设置

### 数据刷新问题

- 点击"刷新数据"按钮手动刷新
- 检查数据库文件是否存在
- 重启应用程序
