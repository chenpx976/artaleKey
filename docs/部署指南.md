# ArtaleKey 部署指南

## 概述

本文档详细介绍了 ArtaleKey 项目的部署流程，包括开发环境搭建、生产环境部署、应用打包和发布等各个环节。

## 开发环境部署

### 系统要求

#### macOS (推荐)
- **操作系统**: macOS 10.15 (Catalina) 或更高版本
- **Python**: 3.8.1 或更高版本
- **内存**: 至少 4GB RAM (推荐 8GB)
- **存储**: 至少 2GB 可用空间
- **权限**: 需要辅助功能权限

#### 其他系统
- **Windows**: Windows 10 或更高版本 (实验性支持)
- **Linux**: Ubuntu 18.04 或更高版本 (实验性支持)

### 环境搭建步骤

#### 1. 安装 Python

**macOS (使用 Homebrew)**:
```bash
# 安装 Homebrew (如果未安装)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python
brew install python@3.11
```

**macOS (官方安装包)**:
- 访问 [Python官网](https://www.python.org/downloads/)
- 下载并安装 Python 3.8.1+

#### 2. 安装 uv 包管理器

```bash
# 使用官方安装脚本
curl -LsSf https://astral.sh/uv/install.sh | sh

# 或使用 pip 安装
pip install uv
```

#### 3. 克隆项目

```bash
git clone https://github.com/chenpx976/artaleKey.git
cd artaleKey
```

#### 4. 创建虚拟环境

```bash
# 创建虚拟环境
uv venv

# 激活虚拟环境
source .venv/bin/activate  # macOS/Linux
# 或
.venv\Scripts\activate     # Windows
```

#### 5. 安装依赖

```bash
# 安装项目依赖
uv pip install -r requirements.txt

# 安装开发依赖 (可选)
uv pip install -r requirements-dev.txt
```

#### 6. 配置权限 (macOS)

1. 打开 **系统偏好设置** > **安全性与隐私** > **隐私**
2. 选择 **辅助功能**
3. 点击锁图标解锁
4. 添加终端应用或 Python 解释器
5. 确保权限已启用

#### 7. 验证安装

```bash
# 启动应用
uv run python -m artalekey

# 检查版本
python --version
uv --version
```

## 生产环境部署

### 应用打包

#### macOS App 打包

1. **安装打包依赖**:
```bash
pip install -r requirements-build.txt
```

2. **运行打包脚本**:
```bash
python build_macos_app.py
```

3. **验证打包结果**:
```bash
# 检查生成的应用
ls -la dist/
open dist/ArtaleKey.app  # 测试启动
```

#### 打包配置说明

**`build_macos_app.py` 关键配置**:
```python
# 应用信息
app_name = "ArtaleKey"
app_version = "1.0.0"
app_identifier = "com.artalekey.app"

# 打包选项
options = {
    'argv_emulation': False,
    'iconfile': 'assets/icon.icns',
    'plist': {
        'CFBundleName': app_name,
        'CFBundleVersion': app_version,
        'NSHighResolutionCapable': True,
        'LSUIElement': False,  # 显示在 Dock 中
    }
}
```

### DMG 安装包制作

#### 1. 准备资源

```bash
# 创建 DMG 工作目录
mkdir -p dmg_build/ArtaleKey

# 复制应用程序
cp -R dist/ArtaleKey.app dmg_build/ArtaleKey/

# 创建应用程序快捷方式
ln -s /Applications dmg_build/ArtaleKey/Applications
```

#### 2. 自定义 DMG 外观

```bash
# 复制背景图片
cp assets/dmg_background.png dmg_build/ArtaleKey/.background.png

# 设置图标位置和窗口大小
# (需要手动在 Finder 中调整)
```

#### 3. 生成 DMG

```bash
# 使用 hdiutil 创建 DMG
hdiutil create -volname "ArtaleKey" \
    -srcfolder dmg_build/ArtaleKey \
    -ov -format UDZO \
    dist/ArtaleKey-1.0.0.dmg
```

### 代码签名和公证

#### 1. 获取开发者证书

1. 注册 Apple Developer Program
2. 在 Keychain Access 中生成证书请求
3. 在 Apple Developer 网站创建证书
4. 下载并安装证书

#### 2. 签名应用

```bash
# 签名应用程序
codesign --force --deep --sign "Developer ID Application: Your Name" \
    dist/ArtaleKey.app

# 验证签名
codesign --verify --verbose dist/ArtaleKey.app
spctl --assess --verbose dist/ArtaleKey.app
```

#### 3. 公证应用

```bash
# 创建公证用的 zip 文件
ditto -c -k --keepParent dist/ArtaleKey.app ArtaleKey.zip

# 提交公证
xcrun notarytool submit ArtaleKey.zip \
    --apple-id "your-apple-id@example.com" \
    --password "app-specific-password" \
    --team-id "TEAM_ID" \
    --wait

# 装订公证票据
xcrun stapler staple dist/ArtaleKey.app
```

## 持续集成/持续部署 (CI/CD)

### GitHub Actions 配置

**`.github/workflows/build.yml`**:
```yaml
name: Build and Release

on:
  push:
    tags:
      - 'v*'
  pull_request:
    branches: [ main ]

jobs:
  build-macos:
    runs-on: macos-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.11'
    
    - name: Install uv
      run: curl -LsSf https://astral.sh/uv/install.sh | sh
    
    - name: Install dependencies
      run: |
        uv venv
        source .venv/bin/activate
        uv pip install -r requirements.txt
        uv pip install -r requirements-build.txt
    
    - name: Run tests
      run: |
        source .venv/bin/activate
        python -m pytest tests/
    
    - name: Build application
      run: |
        source .venv/bin/activate
        python build_macos_app.py
    
    - name: Create DMG
      run: |
        # DMG 创建脚本
        ./scripts/create_dmg.sh
    
    - name: Upload artifacts
      uses: actions/upload-artifact@v3
      with:
        name: ArtaleKey-macOS
        path: dist/ArtaleKey-*.dmg

  release:
    needs: build-macos
    runs-on: ubuntu-latest
    if: startsWith(github.ref, 'refs/tags/')
    
    steps:
    - name: Download artifacts
      uses: actions/download-artifact@v3
    
    - name: Create Release
      uses: softprops/action-gh-release@v1
      with:
        files: |
          ArtaleKey-macOS/ArtaleKey-*.dmg
        draft: false
        prerelease: false
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### 自动化脚本

#### 构建脚本 (`scripts/build.sh`)

```bash
#!/bin/bash
set -e

echo "🚀 开始构建 ArtaleKey..."

# 检查环境
if ! command -v uv &> /dev/null; then
    echo "❌ uv 未安装，请先安装 uv"
    exit 1
fi

# 激活虚拟环境
source .venv/bin/activate

# 清理旧的构建文件
rm -rf dist/ build/

# 安装依赖
echo "📦 安装依赖..."
uv pip install -r requirements-build.txt

# 运行测试
echo "🧪 运行测试..."
python -m pytest tests/ -v

# 构建应用
echo "🔨 构建应用..."
python build_macos_app.py

# 创建 DMG
echo "💿 创建 DMG..."
./scripts/create_dmg.sh

echo "✅ 构建完成！"
echo "📁 输出文件: dist/"
ls -la dist/
```

#### DMG 创建脚本 (`scripts/create_dmg.sh`)

```bash
#!/bin/bash
set -e

APP_NAME="ArtaleKey"
VERSION=$(python -c "import artalekey; print(artalekey.__version__)")
DMG_NAME="${APP_NAME}-${VERSION}"

echo "📀 创建 DMG: ${DMG_NAME}.dmg"

# 创建临时目录
TEMP_DIR=$(mktemp -d)
DMG_DIR="${TEMP_DIR}/${APP_NAME}"
mkdir -p "${DMG_DIR}"

# 复制应用程序
cp -R "dist/${APP_NAME}.app" "${DMG_DIR}/"

# 创建 Applications 链接
ln -s /Applications "${DMG_DIR}/Applications"

# 复制许可证和说明文件
cp README.md "${DMG_DIR}/README.txt"
cp LICENSE "${DMG_DIR}/LICENSE.txt"

# 创建 DMG
hdiutil create -volname "${APP_NAME}" \
    -srcfolder "${DMG_DIR}" \
    -ov -format UDZO \
    "dist/${DMG_NAME}.dmg"

# 清理临时文件
rm -rf "${TEMP_DIR}"

echo "✅ DMG 创建完成: dist/${DMG_NAME}.dmg"
```

## 故障排除

### 常见问题

#### 1. 权限问题
**问题**: 应用启动后快捷键不响应
**解决方案**:
1. 检查辅助功能权限
2. 重新添加应用到权限列表
3. 重启应用程序

#### 2. 依赖问题
**问题**: 导入模块失败
**解决方案**:
```bash
# 重新安装依赖
uv pip install --force-reinstall -r requirements.txt

# 检查 Python 路径
python -c "import sys; print(sys.path)"
```

#### 3. 打包问题
**问题**: 打包后应用无法启动
**解决方案**:
1. 检查打包日志
2. 验证依赖是否完整
3. 测试在干净环境中运行

#### 4. 性能问题
**问题**: OCR 识别速度慢
**解决方案**:
1. 启用 GPU 加速
2. 优化图像预处理
3. 调整缓存设置

## 监控和维护

### 性能监控

#### 系统资源监控
```python
import psutil
import time

def monitor_resources():
    """监控系统资源使用情况"""
    process = psutil.Process()
    
    while True:
        cpu_percent = process.cpu_percent()
        memory_info = process.memory_info()
        
        print(f"CPU: {cpu_percent}%")
        print(f"Memory: {memory_info.rss / 1024 / 1024:.1f} MB")
        
        time.sleep(10)
```

#### 应用性能监控
```python
import time
from functools import wraps

def performance_monitor(func):
    """性能监控装饰器"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        
        duration = end_time - start_time
        print(f"{func.__name__} 执行时间: {duration:.3f}s")
        
        return result
    return wrapper
```
