# ArtaleKey 配置系统优化总结

## 问题分析

在 review `artalekey/core/config.py` 和相关配置应用机制时，发现了几个关键问题：

### 1. 🔥 **快捷键 trigger_key 配置不生效** (严重问题)

**问题现象**：
- 用户在UI中修改快捷键从 'w' 改为 's'，但实际监听的仍然是 'w' 键
- 配置已保存，但热键监听器没有更新

**根本原因**：
1. `HotkeyListener` 类缺少 `set_main_trigger_key()` 方法
2. `_on_hotkey_config_changed()` 方法中没有处理 `trigger_key` 变更
3. `_apply_core_configs()` 初始化时也没有应用 `trigger_key`

### 2. ⚠️ **默认配置不一致**

**问题现象**：
- `config.py` 中默认 interval 为 40ms
- `UIConfigManager` 中默认 interval 为 50ms 
- `UIConfigManager` 缺少 `trigger_key` 和 `enabled` 字段

### 3. 📡 **配置变更信号处理不完善**

**问题现象**：
- 配置变更信号发送，但缺少调试日志
- 信号内容格式不够规范

## 解决方案

### 1. 🔧 **热键监听器增强**

**新增方法**：
```python
def set_main_trigger_key(self, key: str):
    """设置主触发键"""
    with self._lock:
        # 移除旧的监听键
        if self._main_trigger_key in self._monitored_keys:
            self._monitored_keys.discard(self._main_trigger_key)
        
        # 添加新的监听键
        self._main_trigger_key = key.lower()
        self._monitored_keys.add(self._main_trigger_key)
        
        # 清除旧的按键状态
        old_states = dict(self._key_states)
        for old_key in old_states:
            if isinstance(old_key, str) and old_key != self._main_trigger_key and old_key != self._ocr_trigger_key:
                self._key_states.pop(old_key, None)
        
        performance_logger.info(f"Main trigger key set to: {self._main_trigger_key}")
```

**关键特性**：
- ✅ 动态更新监听键集合
- ✅ 清理旧的按键状态，避免冲突
- ✅ 线程安全处理
- ✅ 详细的日志记录

### 2. 🔗 **配置应用机制完善**

**启动时配置应用**：
```python
def _apply_core_configs(self, all_configs: dict):
    # 应用快速向上配置
    quick_up_config = all_configs.get('quick_up', {})
    hotkey_config = quick_up_config.get('hotkey_config', {})
    if hotkey_config:
        self.hotkey_listener.set_hold_time(hotkey_config.get('hold_time', 500))
        self.key_simulator.set_interval(hotkey_config.get('interval', 50))
        # 新增：应用主触发键配置
        trigger_key = hotkey_config.get('trigger_key', 'w')
        self.hotkey_listener.set_main_trigger_key(trigger_key)
```

**运行时配置变更**：
```python
def _on_hotkey_config_changed(self, hotkey_id: str, config: dict):
    if hotkey_id == "default":
        # 应用所有热键配置
        self.hotkey_listener.set_hold_time(config.get('hold_time', 500))
        self.key_simulator.set_interval(config.get('interval', 50))
        # 新增：处理主触发键变更
        trigger_key = config.get('trigger_key', 'w')
        self.hotkey_listener.set_main_trigger_key(trigger_key)
        performance_logger.info(f"热键配置已更新 - 触发键: {trigger_key}, 长按时间: {config.get('hold_time', 500)}ms, 间隔: {config.get('interval', 50)}ms")
```

### 4. 📊 **配置变更信号优化**

**改进信号处理**：
```python
def set(self, key: str, value: Any, auto_save: bool = True):
    # 发送变更信号（优化信号发送逻辑）
    if old_value != value:
        # 构建完整的配置路径和值
        signal_value = value if isinstance(value, dict) else {'value': value}
        self.config_changed.emit(key, signal_value)
        performance_logger.debug(f"配置已变更: {key} = {signal_value}")
```
