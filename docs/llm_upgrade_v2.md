# ArtaleKey LLM 系统升级 v2.0

## 更新概述
本次更新将 ArtaleKey 的图像识别系统从简单的区域截图升级为使用完整截图的智能识别系统，并大幅扩展了可识别的游戏信息。同时修复了多个关键问题。

## 主要改进

### 1. 截图策略优化
- **之前**: 只截取游戏窗口的下方 1/4 区域
- **现在**: 截取完整的游戏窗口或全屏
- **优势**: 能够识别更多界面元素，获取更丰富的游戏信息

### 2. 识别信息扩展
原先只能识别:
- 角色等级
- 当前等级最大 HP
- 当前等级最大 MP  
- 当前经验值
- 当前经验值百分比

现在可以识别:
- ✅ 角色等级
- ✅ **角色名称** (新增)
- ✅ **角色职业** (新增)
- ✅ **当前地图名称** (新增)
- ✅ 当前等级最大 HP
- ✅ 当前等级最大 MP
- ✅ 当前经验值
- ✅ 当前经验值百分比
- ✅ **角色当前持有金钱** (新增)

### 3. LLM 提示词优化
从 YAML 格式改为更可靠的 JSON 格式：

```
你是一个冒险岛游戏的高级玩家，可以根据我发送给你的截图，分析获取到下面的信息，输出为标准JSON格式：

请返回以下JSON结构，严格按照字段名输出：
{
  "level": 角色等级 (数字),
  "character_name": "角色名称" (字符串),
  "character_class": "角色职业" (字符串),
  "map_name": "当前地图名称" (字符串),
  "max_hp": 当前等级最大HP (数字),
  "max_mp": 当前等级最大MP (数字),
  "experience_value": 当前经验值 (数字),
  "experience_percentage": 当前经验值百分比 (数字，不含%符号),
  "money": 角色当前持有金钱 (数字)
}

注意事项：
- 仔细观察截图中的所有界面元素，包括状态栏、角色信息面板、地图名称等
- 如果某个信息不可见或无法确定，请设置为null
- 数字字段请只输出纯数字，不包含逗号、单位等
- 百分比字段请只输出数字部分，如65.5而不是65.5%
- 请确保输出为有效的JSON格式
```

### 4. 数据库结构升级
新增数据库字段:
- `character_name` TEXT - 角色名称
- `character_class` TEXT - 角色职业  
- `map_name` TEXT - 地图名称
- `max_hp` INTEGER - 最大HP
- `max_mp` INTEGER - 最大MP

相关索引:
- `idx_character_name` - 角色名称索引
- `idx_level` - 等级索引
- `idx_map_name` - 地图名称索引

### 5. 字段映射优化
- **移除复杂的字段映射逻辑**：不再需要中英文字段映射
- **直接使用标准字段名**：JSON 格式确保字段名一致性
- **简化数据清理**：更可靠的数据类型转换
- **增强错误处理**：更好的异常处理和日志记录

## 关键问题修复

### 🚀 问题1：LLM 处理时应用卡住
**问题**: 在执行 LLM 图片处理时整个应用程序卡住
**修复**:
- 改为异步处理：使用 `ThreadPoolExecutor` 在后台线程执行 LLM 调用
- 添加进度监控：使用 `QTimer` 检查异步处理结果
- 回调机制：处理完成后通过回调更新 UI
- 防止阻塞：主线程不再等待 LLM 响应

### 🔧 问题2：API 密钥每次启动都要重新输入
**问题**: 保存的 API 密钥在重启应用后丢失
**修复**:
- 修复配置加载逻辑：启动时自动加载已保存的 API 密钥
- 自动填充输入框：将保存的密钥显示在设置页面
- 自动初始化 LLM：启动时如果有密钥则自动配置 LLM 处理器
- 状态同步：确保 UI 和后端 LLM 处理器的密钥状态一致

### 📊 问题3：可视化缺少角色筛选
**问题**: 可视化界面只能按等级筛选，不能按角色筛选
**新增功能**:
- **角色下拉框**：显示所有存在的角色
- **级联筛选**：选择角色后，等级下拉框只显示该角色的等级
- **组合筛选**：支持同时按角色和等级筛选数据
- **状态保存**：记住用户选择的角色和等级
- **动态更新**：当数据更新时自动刷新角色列表

### 📝 问题4：数据格式标准化
**问题**: YAML 格式容易产生解析错误，字段映射复杂
**优化**:
- **JSON 格式**：更可靠的数据交换格式
- **标准字段名**：统一使用英文字段名，避免映射
- **类型验证**：严格的数据类型检查和转换
- **错误恢复**：更好的解析错误处理

## 使用方法

### 首次设置
1. 启动应用程序
2. 进入"设置"标签页
3. 在"LLM API 配置"区域输入您的 OpenRouter API 密钥
4. 点击"保存 API 密钥"按钮
5. ✅ **密钥将自动保存，下次启动无需重新输入**

### 触发识别
1. 确保目标游戏窗口处于激活状态
2. 在 ArtaleKey 中点击"截图识别"按钮或按 C 键
3. ✅ **系统将异步处理，不会卡住应用程序**
4. 等待识别完成（通常 5-10 秒）

### 查看结果
- **实时数据显示**：主界面显示最新识别结果
- **历史数据**：保存在数据库中
- **可视化分析**：支持按角色和等级筛选的趋势分析
- **数据导出**：支持导出为 JSON 格式
