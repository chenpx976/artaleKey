# ArtaleKey 开发文档

## 项目概述

ArtaleKey 是一个专为 macOS 设计的快捷键管理器，主要用于游戏辅助，特别是针对 MapleStory Worlds 等游戏进行了优化。项目采用 Python + PyQt6 技术栈，提供了现代化的用户界面和强大的功能。

### 核心功能
- 🎮 游戏快捷键管理
- 🖼️ OCR 文字识别
- 🤖 LLM 智能处理
- 📊 数据可视化
- 🪟 窗口检测与过滤
- ⚡ 性能监控

### 模块结构

#### UI 层 (`artalekey/ui/`)
- `tabbed_main_window.py` - 主窗口和标签页管理

- `window_status_widget.py` - 窗口状态显示组件
- `components.py` - 通用UI组件
- `simple_target_selector.py` - 目标选择器
- `simple_styles.py` - 样式定义

#### 核心层 (`artalekey/core/`)
- `hotkey_manager.py` - 快捷键管理核心
- `enhanced_ocr.py` - OCR文字识别引擎
- `llm_processor.py` - LLM智能处理
- `window_detector.py` - 窗口检测与过滤
- `window_status.py` - 窗口状态管理
- `database.py` - 数据存储管理
- `config.py` - 配置管理
- `logger.py` - 日志系统

## 核心模块详解

### 1. 快捷键管理 (HotkeyManager)

**功能**: 管理全局快捷键的注册、监听和处理

**关键特性**:
- 支持组合键 (Ctrl+Alt+Key)
- 游戏窗口检测
- 快捷键冲突检测
- 动态快捷键注册

**使用示例**:
```python
from artalekey.core.hotkey_manager import HotkeyManager

manager = HotkeyManager()
manager.register_hotkey('w+up', callback_function)
manager.start_listening()
```

### 2. OCR 引擎 (EnhancedOCR)

**功能**: 高性能文字识别和图像处理

**关键特性**:
- 多引擎支持 (EasyOCR, Tesseract)
- 图像预处理优化
- 批量识别
- 结果缓存

**使用示例**:
```python
from artalekey.core.enhanced_ocr import EnhancedOCR

ocr = EnhancedOCR()
result = ocr.recognize_text(image_path)
```

### 3. LLM 处理器 (LLMProcessor)

**功能**: 智能文本处理和分析

**关键特性**:
- 多模型支持
- 上下文管理
- 结果优化
- 错误处理

### 4. 窗口检测器 (WindowDetector)

**功能**: 检测和过滤目标应用窗口

**关键特性**:
- 实时窗口监控
- 应用程序识别
- 窗口状态跟踪
- 过滤规则管理

## 数据存储

### 数据库设计
项目使用 SQLite 作为本地数据库，主要表结构：

- `hotkeys` - 快捷键配置
- `ocr_results` - OCR识别结果
- `window_status` - 窗口状态记录
- `performance_logs` - 性能监控数据

### 配置管理
配置文件采用 YAML 格式，支持：
- 用户偏好设置
- 快捷键配置
- OCR参数
- 性能参数

## 性能优化

### OCR 优化策略
1. **图像预处理**: 灰度化、降噪、二值化
2. **区域检测**: 智能裁剪识别区域
3. **结果缓存**: 避免重复识别
4. **多线程处理**: 并行处理多个任务

### 内存管理
1. **对象池**: 复用重量级对象
2. **垃圾回收**: 及时释放不用的资源
3. **内存监控**: 实时监控内存使用

### UI 响应性
1. **异步处理**: 耗时操作放在后台线程
2. **进度反馈**: 提供操作进度提示
3. **懒加载**: 按需加载UI组件

## 常见问题

### 开发环境问题

**Q: 启动时提示权限错误**
A: 需要在系统偏好设置中授予辅助功能权限

**Q: OCR识别效果不佳**
A: 检查图像质量，调整预处理参数

**Q: 快捷键不响应**
A: 确认目标应用窗口处于活跃状态

### 性能问题

**Q: 内存占用过高**
A: 检查是否有内存泄漏，及时释放不用的资源

**Q: OCR识别速度慢**
A: 优化图像预处理，使用GPU加速
