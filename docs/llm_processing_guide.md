# LLM 图片处理使用指南

## 概述

ArtaleKey 现已完全使用 LLM（大语言模型）来处理游戏界面截图，代替了之前的 OCR 识别方式。新的处理方式更加准确和智能。

## 功能特点

- **无需预处理**：直接将原始截图发送给 LLM 处理
- **智能识别**：使用 Qwen2.5-VL 72B 模型（免费），能够准确识别各种游戏界面元素
- **多信息提取**：可同时提取等级、HP、MP、经验值等多种信息
- **高精度**：相比传统 OCR，LLM 能更好地理解图像内容
- **图形界面配置**：在设置页面直接配置 API 密钥，无需命令行操作

## 配置要求

### 1. 获取 API 密钥

1. 访问 [OpenRouter](https://openrouter.ai/)
2. 注册账号并获取 API 密钥
3. 记录您的 API 密钥备用

### 2. 在应用中配置

1. 启动 ArtaleKey 应用
2. 点击"设置"标签页
3. 在"LLM API 配置"区域输入您的 OpenRouter API 密钥
4. 点击"保存 API 密钥"按钮
5. 确认状态显示为"已配置"

## 处理流程

### 1. 截图采集

- 自动检测目标游戏窗口（默认：MapleStory Worlds）
- 只截取窗口底部四分之一区域
- 支持高分辨率显示器

### 2. LLM 处理

- 将截图转换为 base64 格式
- 发送给 Qwen2.5-VL 72B 模型进行分析
- 使用专门的提示词指导模型提取游戏数据

### 3. 数据提取

模型会尝试提取以下信息：

- **等级**：角色当前等级
- **最大 HP**：当前等级的最大生命值
- **最大 MP**：当前等级的最大魔法值
- **当前经验值**：经验数值
- **经验百分比**：当前等级经验进度百分比

## 提示词模板

```
提取图片中的下面相关信息，输出在 <output/> 中，使用 yaml 格式
等级
当前等级最大 HP
当前等级最大 MP
当前经验值
当前经验值百分比
```

## 输出格式

LLM 会以 YAML 格式返回识别结果：

```yaml
等级: 150
当前等级最大 HP: 25000
当前等级最大 MP: 15000
当前经验值: 1250000
当前经验值百分比: 65.5
```

## 数据存储

处理结果会保存到以下位置：

- **截图**：`screenshots/screenshot_YYYYMMDD_HHMMSS.png`
- **LLM 结果**：`llm_results/llm_result_YYYYMMDD_HHMMSS.json`
- **汇总数据**：`game_data_summary.json`
- **配置文件**：API 密钥安全存储在本地配置文件中

## 性能优化

### 1. 图片压缩

- 自动将图片压缩到 1024x1024 以内
- 减少 API 调用成本
- 保持识别精度

### 2. 缓存机制

- 检测重复截图，使用缓存结果
- 窗口边界信息缓存 5 秒
- 避免不必要的 API 调用

### 3. 错误处理

- API 调用失败时的详细错误信息
- 解析错误的降级处理
- 详细的错误日志记录

## API 成本控制

### 1. 免费模型

- 使用 **qwen/qwen2.5-vl-72b-instruct:free** 模型
- 完全免费，无需付费
- 识别精度优秀

### 2. 图片优化

- 只截取相关区域（底部四分之一）
- 智能压缩，保持关键信息
- 避免发送全屏截图

### 3. 调用频率

- 手动触发模式（按 C 键）
- 智能去重，避免重复处理
- 无自动定时触发，完全由用户控制

## 故障排除

### 1. API 密钥问题

- 在设置页面检查 API 密钥配置状态
- 确保密钥正确且有效
- 重新保存 API 密钥

### 2. 网络连接问题

- 确保网络连接正常
- 检查防火墙设置
- 使用 VPN 或代理（如需要）

### 3. 识别精度问题

- 确保游戏界面清晰
- 避免界面被其他窗口遮挡
- 调整游戏界面大小以获得最佳效果

## 相比 OCR 的优势

1. **更高准确率**：LLM 能更好地理解图像上下文
2. **更强容错性**：对图像质量要求较低
3. **多语言支持**：天然支持多种语言界面
4. **智能解析**：能理解复杂的界面布局
5. **持续改进**：模型能力持续提升
6. **免费使用**：使用免费模型，无需付费

## 技术规格

- **模型**：qwen/qwen2.5-vl-72b-instruct:free
- **API 提供商**：OpenRouter
- **支持格式**：PNG、JPEG 等常见图片格式
- **最大输入尺寸**：自动压缩到 1024x1024
- **输出格式**：JSON 结构化数据

## 安全性

1. **本地存储**：API 密钥仅存储在本地配置文件中
2. **加密传输**：使用 HTTPS 加密传输数据
3. **隐私保护**：可随时删除存储的截图和数据
4. **密钥隐藏**：UI 中自动隐藏 API 密钥显示
