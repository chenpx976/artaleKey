# macOS 权限管理功能指南

## 概述

ArtaleKey 在 macOS 系统上需要三个关键权限才能正常工作：

1. **🔧 辅助功能权限** - 用于模拟按键操作和监听全局快捷键
2. **⌨️ 输入监控权限** - 用于检测全局快捷键组合
3. **📺 屏幕录制权限** - 用于截图和OCR文字识别功能

## 功能特性

### 自动权限检查
- 应用启动时自动检查所有权限状态
- 每30秒自动刷新权限状态
- 实时显示权限状态（已授予/未授予/未确定）

### 一键权限请求
- 点击"请求权限"按钮自动打开系统设置
- 智能引导用户完成权限授予流程
- 支持直接打开对应的隐私设置页面

### 权限状态显示
- ✅ 已授予 - 绿色显示，隐藏请求按钮
- ❌ 未授予 - 红色显示，显示请求按钮
- ❓ 未确定 - 橙色显示，显示请求按钮
- ➖ 不适用 - 灰色显示（非macOS系统）

## 使用方法

### 1. 打开设置页面
在 ArtaleKey 主界面中点击"设置"标签页。

### 2. 查看权限状态
在"macOS 系统权限"组中查看当前权限状态。

### 3. 请求权限
对于未授予的权限，点击对应的"请求权限"按钮：

#### 辅助功能权限
- 点击按钮后会弹出系统权限请求对话框
- 点击"打开系统偏好设置"
- 在辅助功能列表中勾选 ArtaleKey

#### 输入监控权限
- 点击按钮后自动打开输入监控设置页面
- 在列表中勾选 ArtaleKey
- 设置完成后重启应用

#### 屏幕录制权限
- 点击按钮后会弹出系统权限请求对话框
- 点击"允许"即可

### 4. 验证权限
- 点击"🔄 刷新权限状态"按钮手动刷新
- 或等待自动刷新（每30秒）
- 确认所有权限都显示为"✅ 已授予"

## 故障排除

### 权限请求失败
如果自动权限请求失败，可以手动设置：

1. 打开"系统偏好设置"
2. 选择"安全性与隐私"
3. 点击"隐私"标签
4. 在左侧列表中选择对应权限类型
5. 点击🔒解锁
6. 添加 ArtaleKey 到允许列表

### 权限状态不更新
- 点击"🔄 刷新权限状态"按钮
- 重启应用程序
- 重启系统（某些权限更改需要重启）

### 快捷键不工作
确保以下权限都已授予：
- [ ] 辅助功能权限
- [ ] 输入监控权限
- [ ] 屏幕录制权限（如果使用OCR功能）

## 技术实现

### 权限检查方法
- **辅助功能**: 使用 `AXIsProcessTrusted()` API 或 AppleScript 备用方法
- **输入监控**: 尝试创建 pynput 监听器测试
- **屏幕录制**: 使用 `CGPreflightScreenCaptureAccess()` API 或 screencapture 命令测试

### 权限请求方法
- **辅助功能**: 使用 `AXIsProcessTrustedWithOptions()` 显示系统对话框
- **输入监控**: 打开系统偏好设置的输入监控页面
- **屏幕录制**: 使用 `CGRequestScreenCaptureAccess()` 显示系统对话框

### 备用方案
当 PyObjC 不可用时，使用以下备用方案：
- AppleScript 检查辅助功能权限
- screencapture 命令测试屏幕录制权限
- 直接打开系统偏好设置页面

## 注意事项

1. **仅限 macOS**: 权限管理功能仅在 macOS 系统上可用
2. **需要重启**: 某些权限更改后需要重启应用才能生效
3. **系统版本**: 输入监控权限需要 macOS 10.15+ 版本
4. **代码签名**: 已签名的应用权限请求更稳定可靠
