# 日志标签页使用指南

## 概述

日志标签页是 ArtaleKey 的实时日志监控功能，可以帮助您：
- 📊 **实时查看程序运行日志**
- 🔍 **按级别过滤日志信息**
- 💾 **保存日志到文件**
- ⚡ **高性能日志显示**

## 功能特性

### 🎯 实时日志显示
- 自动捕获程序运行时的所有日志
- 支持不同级别的日志颜色区分
- 100ms 高频率更新，确保实时性

### 🔧 日志控制面板
- **级别过滤**: 选择显示特定级别的日志（全部/DEBUG/INFO/WARNING/ERROR）
- **自动滚动**: 自动滚动到最新日志
- **最大行数**: 控制显示的最大日志行数（100-50000行）
- **暂停/继续**: 暂停日志更新以便查看
- **清空**: 清空当前显示的所有日志
- **保存日志**: 将日志导出到文本文件

### 🎨 视觉特性
- **深色主题**: 护眼的深色背景
- **等宽字体**: 使用 Consolas/Monaco 等宽字体
- **颜色编码**: 
  - 🔘 DEBUG: 灰色
  - ⚫ INFO: 黑色  
  - 🟠 WARNING: 橙色
  - 🔴 ERROR: 红色

### 📊 性能监控
- **日志统计**: 显示总日志数和过滤后的显示数
- **更新性能**: 显示界面更新耗时
- **内存优化**: 使用循环缓冲区，限制内存使用

## 使用方法

### 1. 查看日志
1. 点击"日志"标签页
2. 程序运行时会自动显示日志信息
3. 日志会按时间顺序实时更新

### 2. 过滤日志
1. 在"级别过滤"下拉框中选择要显示的日志级别
2. 选择"全部"显示所有级别的日志
3. 选择特定级别只显示该级别及以上的日志

### 3. 控制显示
- **自动滚动**: 勾选后自动滚动到最新日志
- **最大行数**: 调整显示的最大日志行数，避免内存占用过多
- **暂停**: 点击暂停按钮停止日志更新，方便查看历史日志

### 4. 保存日志
1. 点击"保存日志"按钮
2. 选择保存位置和文件名
3. 日志将以文本格式保存，包含完整的时间戳和级别信息

### 5. 生成测试日志
- 点击"生成测试日志"按钮可以生成一些示例日志
- 用于测试日志功能是否正常工作

## 日志级别说明

### DEBUG 🔘
- 详细的调试信息
- 通常只在开发和调试时需要
- 默认情况下可能不显示

### INFO ⚫
- 一般信息消息
- 程序正常运行的状态信息
- 用户操作记录

### WARNING 🟠
- 警告信息
- 程序遇到了问题但可以继续运行
- 需要注意但不会导致程序崩溃

### ERROR 🔴
- 错误信息
- 程序遇到了错误，某些功能可能无法正常工作
- 需要用户关注和处理

## 故障排除

### 日志不显示
1. 检查日志级别过滤设置
2. 确认程序正在运行并产生日志
3. 尝试点击"生成测试日志"验证功能

### 性能问题
1. 减少最大显示行数
2. 使用级别过滤减少显示的日志量
3. 定期清空日志缓存

### 日志保存失败
1. 检查文件保存路径的写入权限
2. 确保磁盘空间充足
3. 尝试保存到不同的位置

## 技术实现

### 高性能设计
- **异步日志处理**: 使用信号槽机制避免阻塞UI
- **批量更新**: 100ms间隔批量更新界面
- **内存管理**: 使用deque循环缓冲区，自动清理旧日志
- **线程安全**: 使用QMutex确保多线程安全

### 日志捕获
- **自定义Handler**: 继承logging.Handler捕获所有日志
- **格式化**: 统一的日志格式，包含时间、模块、级别、消息
- **实时传输**: 通过Qt信号实时传输到UI线程

### 界面优化
- **虚拟滚动**: 只渲染可见区域的日志
- **颜色缓存**: 预定义颜色格式，避免重复创建
- **智能滚动**: 自动检测是否需要滚动到底部

## 配置选项

日志标签页的配置会自动保存，包括：
- 级别过滤设置
- 自动滚动开关
- 最大行数设置

这些设置在下次启动时会自动恢复。

## 注意事项

1. **内存使用**: 大量日志会占用内存，建议定期清空或调整最大行数
2. **性能影响**: 高频率的日志输出可能影响程序性能
3. **文件大小**: 保存的日志文件可能很大，注意磁盘空间
4. **隐私信息**: 日志中可能包含敏感信息，保存时请注意安全
